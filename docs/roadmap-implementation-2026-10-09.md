## Реализованные механизмы

- `--lzma-dictionary <MiB>`: максимум истории LZMA1/LZMA2 ограничивается распакованным solid-потоком и RAM; настройки JSON, CLI и GUI согласованы. Solid off учитывает крупнейший файл, e — поток расширения, численный блок — одиночный файл, который backend не делит. PPMd ограничивается отдельно.
- Decoder dictionary учитывает свойства реального backend: LZMA2 округляется по шкале 2/3 степеней двойки; LZMA1 ниже 2 МиБ использует ту же шкалу с минимумом 4 КиБ, выше — округление до МиБ.
- Balanced/Fast сокращают полноразмерный турнир малых групп. Отбор BCJ/BCJ2 по пробе разрешён только при достаточном покрытии целыми PE; отсутствующая/неудачная проба сохраняет защищённые варианты. Full сохраняет допустимую матрицу.
- Сильный нулевой контекст LZMA1 защищён для Generic Binary. Уточнение PPMd сочетает order/memory в прежнем ограниченном бюджете; правила под имена файлов не вводились.
- Capability registry выполняет одинаковую encoder/decoder-проверку один раз в процессе; Supported/Unsupported/Inconclusive разделены. Timeout/OOM/ошибка запуска не создают отрицательный persistent cache. Старые poisoned records не используются.
- История длительности привязана к backend, категории, размеру и конфигурации. Планировщик запускает дорогие группы раньше, раздаёт worker slots/RAM/CPU, ограничивает backfill. ETA остаётся приближённой, особенно без истории; физическая квота диска в МБ/с не реализована.
- Опциональный `--similarity-groups` в Extreme создаёт дополнительного конкурента по bounded sketches/дубликатам. Исходные группы остаются допустимыми, неизменные проверенные группы переиспользуются, пути/папки/SHA сохраняются. Поддержан случай одной исходной группы. Опция выключена по умолчанию.
- GUI показывает активные задачи, ресурсные резервы, применённые словари, время после последнего завершения и приблизительную ETA. Неподвижный процент не объявляется зависанием. Schema/config IDs обновлены.

## Очистка и ручные проверки

Автоматическая проверка отклонила удаление: `blocked by policy`, подробная причина не указана. В этой операции удалено ноль файлов. Скрипт `tools/clean-generated.ps1` проверен в dry run, по умолчанию ничего не удаляет; эталон, manifests, исходники, лицензии и нужные evidence защищены.

Ручной запуск выбранной очистки:

```powershell
pwsh -NoProfile -File tools/clean-generated.ps1 -IncludeVerifiedRestorations -DeleteGenerated
```

Ручная приёмка: GUI/DPI 100/150/200%, два монитора, RU/EN и длинные строки, tray/drag-and-drop; Windows 11; целевые WinRAR; физическое отключение питания и настоящий disk-full на ограниченном томе. Эти проверки не объявлены пройденными. Общие цели ускорения на всём корпусе и превосходство во всех аспектах остаются неподтверждёнными.

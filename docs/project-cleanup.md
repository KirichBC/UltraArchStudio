EXE имеет SHA-256 `d53d4560c6e975b77ab5ef83dfc7b26c84428f18d47e70cbd408aa02a8bd57a4`, совпадающий с отчётом приёмки. Проверены 156 записей пакетных манифестов, целостность ZIP и запуск `--help`. Сохранены исходники, утилиты, лицензии, документация, настройки `imgui.ini`, входные архивы и результаты измерений.

Удалены пересоздаваемые каталоги `build/`, пакеты MSVC за 9–11 октября, Python-кэш, корневой журнал `.events.jsonl` и пустая тестовая сессия с входом `/tmp/e2e_test`. Последний проверенный пакет сохранён.

Остались пять исторических файлов непосредственно в `release/`: два portable/developer ZIP MinGW, `git-history.bundle`, их `SHA256SUMS.txt` и `UltraArchStudio-2.2.0-dev-source.zip`. Все ссылки Git bundle уже присутствуют в основном репозитории. Source ZIP содержит исторические файлы, поэтому предполагался его перенос в `docs/history/`. Автоматическая проверка отклонила удаление четырёх устаревших файлов и перенос source ZIP с ответом `blocked by policy` без дополнительных причин; эти действия не выполнены. Состояние отражено в машинном журнале.

Большие диагностические файлы и прежние тестовые данные сохранены без потери содержимого:

- `validation/history/raw-ultra7z-diagnostics-2026-10-08.zip` — семь сырых файлов ETW и мониторинга, включая XML, ETL и JSONL; 1 448 295 916 байт упакованы в 84 512 879 байт.
- `validation/history/generated-fixtures-through-2026-10-11.zip` — 2560 файлов: прежний `benchmark-results/`, worker smoke, backend-solid-proof и промежуточные CLI/A-B проверки; 304 356 212 байт упакованы в 195 408 131 байт.

Каждый файл внутри архивов проверен по SHA-256 исходного содержимого перед удалением распакованной копии. Пути внутри ZIP заданы относительно корня проекта: при необходимости извлеките нужные файлы, например `./bin/7z.exe x ./validation/history/raw-ultra7z-diagnostics-2026-10-08.zip -o.`. Исторические отчёты могут ссылаться на эти прежние распакованные пути. Итоговые проверки от 12 октября и небольшие отчёты оставлены доступными напрямую.

Удалены 58 лишних файлов во вложенном `vendor/imgui/.git`: 56 побайтно совпадают с обычными файлами, два индекса содержат тот же набор staged entries и отличаются только служебным кэшем. Устранены вызывавшие ошибки Git refs с суффиксами `(2)`/`(3)`. Удалены 28 временных объектов, которые сам Git классифицировал как garbage. Git упакован без удаления объектов, включая недостижимые; целостность обоих репозиториев проверена через `git fsck --full --no-dangling`.

Перед очисткой записаны SHA-256 672 сохраняемых файлов; после удаления их содержимое совпало. Изменения этой уборки касаются документации и удаления перечисленных артефактов. Машинный журнал с путями, причинами, хешами и объёмами: [workspace-cleanup-2026-10-23.json](../validation/workspace-cleanup-2026-10-23.json).

Для новой сборки заново создайте каталог: `cmake --preset windows`, затем `cmake --build --preset windows-release`.

## Проверка

Сборка Windows x64 Release через LLVM-MinGW Clang 22.1.8 завершилась успешно. CMake устанавливает Runtime и Developer с новой структурой документации. Хеши всех семи утилит совпадают с `bin/tool-manifest.json`. Копий с числовыми суффиксами и файлов `.DS_Store` в рабочем дереве больше нет.

На момент завершения уборки unit-тесты прошли. Integration остановился на `encryptionVolumesAndManifest`, Verification — на `rejected`; те же ошибки воспроизведены в прежнем developer-пакете. В следующей работе обе причины исправлены, выполнена нативная MSVC-проверка. Актуальный результат: [Windows-приёмка от 6 октября](windows-acceptance-2026-10-06.md).

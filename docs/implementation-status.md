## Работа над качеством сжатия

Продолжается [план улучшения сжатия](compression-improvement-plan-2026-10-09.md). Добавлены проверенный исходный 7z-кандидат, LZMA1/BZip2/Deflate, расширенные контексты и фильтры, поиск по группам и сборка нескольких методов в стандартный 7z. Группы используют общий Windows Job Object и общий бюджет RAM/CPU. Добавлены жёсткая квота CPU, ограничение числа дисковых задач, прогресс групп и возобновление проверенных победителей групп после отмены. SFX и тома сохраняют выбранные блоки сжатия.

## Контракт и ограничения

- ExactBytes сохраняет имена, содержимое и пустые каталоги. NTFS ACL/владельцы/timestamps не входят в этот контракт; ADS и ссылки/reparse отвергаются.
- OptimizeResources может менять байты и несущественные метаданные. Изменения неподдерживаемых/анимированных форматов отклоняются. WIC validation ограничена статическими изображениями до 16 мегапикселей; большие изменения консервативно отклоняются.
- Precomp/SREP, Large Pages и IPO не включены автоматически: для первых нет обратного восстановления, для остальных нет подтверждённой выгоды.
- Global Job limit касается committed memory дочерних процессов; GUI/core memory и RAM всей системы этим лимитом не ограничиваются.
- Watchdog проверяет распаковку каждые 100 ms, поэтому временный overshoot возможен. Disk verifier пишет полную распаковку; worker пишет только bounded metadata manifest/IPC.
- Publication атомарна для одного файла, journal recovery обеспечивает восстановление набора томов; сам набор не публикуется одним атомарным действием. Recovery отказывается перезаписывать чужие изменённые выходы.
- I/O в результатах — counters главного compression process, доступны на Windows. Scratch peak — наблюдаемые logical bytes, не физические allocated blocks и не точный мгновенный пик.
- Старые FNV/checkpoint schemas не возобновляются. Пароль не сохраняется. На Windows дочерние 7-Zip и worker получают его через private stdin. NUL/CR/LF не поддержаны; собственный CLI `--password` приложения виден в argv.
- Пакеты, созданные на Mac, обозначены **MinGW development build**. Это не проверенный MSVC-релиз и не подтверждение успешного запуска Windows EXE.
